## 正文

### 这是啥

TipCL 是一个 Minecraft 启动器,Windows 与 Linux 两条实现都在同一个仓库里,规划、审计、进度都公开写。
这一版(v1.3)主要干了两件事:**把自定义界面整套重做**,和**把几处安全边界扎紧**。

### 这版的变化

**布局 v3:编辑界面重做**

- 编辑布局从页面底部一排挤在一起的文字按钮,变成内容区顶部一条工具条:左边「编辑「下载」页」,中间「列表 / 网格」,右边撤销 / 重做 / 「添加」/「重置本页」/「完成」。
- 区块换成灰色虚线框,块名悬停才出现;自建组件显示你自己起的名字,不再冒出 `w_note1` 这种内部编号。
- 新增「添加」抽屉:上半是「本页已隐藏的内容」,下半是组件库;加完页面自动滚到新块。
- 设置 → 布局重排成**外观 / 导航 / 页面 / 方案 / 高级**五组;页面变成缩略图卡片网格,「全部恢复默认」一眼能找到。
- 布局 JSON 挪进独立窗口,不再在页面上常驻一个 JSON 框。

**Linux 版补齐一大批 AI 工具**

排错(读日志、读崩溃报告、列目录、读文件、打开所在文件夹)、卡顿与存档(硬件诊断、按实例调内存与 GC、存档备份与回滚)、账号与皮肤、服务器延迟与 SRV 查询、启动前预检(Java / 前置模组 / 加载器 / 内存)、一键导出诊断报告(自动打码令牌与用户名)。

**安全边界**

- MCP Server:只收 `application/json` 的 POST;`Origin: null`(sandbox iframe / 本地 html)与非环回 `Host`(DNS rebinding)一律 403。以前网页能借浏览器打本机接口,现在打不进来了。
- **Windows 版外部 AI 发起的写操作也开始弹确认**(以前是直接执行),和 Linux 版对齐:没有确认界面、你点了拒绝、或者 120 秒没人点,一律按拒绝处理并返回 `permission_denied`。
- Linux 版微软账号令牌不再每次重启丢:优先存系统密钥环(GNOME Keyring / KWallet),没有密钥环就存到数据目录下**权限 600** 的凭据文件;`accounts.json` 也收紧到 600。
- Linux 包开始附 `.sha256`(AppImage 与 `.deb` 各一份),下载后可以自己核对。

### 下载与校验

- Release 页:`https://github.com/wfwwq/TipCL/releases/tag/v1.3.0`
- Windows:`TipCL.exe`(未签名,首次运行 SmartScreen 会提示,点「更多信息 → 仍要运行」)
- Linux:`TipCL-linux-x64.AppImage`(自包含免安装)、`tipcl_1.3.0_amd64.deb`
- 每个产物都带同名 `.sha256`(一行 64 位十六进制):
  ```bash
  sha256sum -c TipCL-linux-x64.AppImage.sha256
  ```

### 想听什么反馈

1. **布局 v3 的手感** —— 拖块跟不跟手、虚线框和悬停标签看得清不清、「添加」抽屉找得到东西吗。
2. **Linux 版** —— 你的发行版上密钥环走通了没有(重启还提不提示登录),以及 AI 工具在真机上顺不顺。
3. **MCP 那条确认弹窗** —— 会不会太吵?哪些工具你觉得不该每次问?(现在是所有写操作都问。)
