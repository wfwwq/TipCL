# 布局 v2 快速上手 + 常见问题(1.2.0)

面向普通玩家/群友:**想干什么 → 怎么点**。每个操作都在 `windos/src/TipCL/**` 里核实过;
没在真机上实测过的会显式标「未实测」。想要一步步的详细说明看另一份「布局使用指南」,这里是短版。

> **平台范围(必读,2026-11-20 复核)**:本文写的是 **Windows 桌面版**(`windos/src/TipCL/**`)。Linux 移植树已经落地
> 布局 v2 的文档 / 引擎 / 编辑器 / 右键「自定义布局...」/ 自建区块渲染、设置页「布局」7 小节、分栏比例、整机方案、
> 布局 JSON 卡片、页签与标题栏编辑;**唯一还缺的是 AI 排版(`layout_apply` / 「AI 备份」)**。
> 但**编辑态的手感两侧并不一样**(Linux 把 stack 页临时折成 12 列网格再拖),逐条见
> [docs/README.md](README.md) 的「布局 v2:Linux 移植版的真实进度」与「Linux 编辑态与 Windows 的四处差异」。

## 一、30 秒版

| 想干什么 | 怎么操作 |
|---|---|
| 进编辑态 | 页面上**右键 →「自定义布局...」**(页面里有 2 个以上区块才会出现这一项) |
| 进编辑态(备用入口) | **设置 → 布局 →「页面区块」**,点那一页的「自定义布局...」按钮(跳过去并进入编辑) |
| 换顺序 | 拖区块顶部操作条上的**拖拽手柄**:块跟着手指走,越过相邻块中点才换位,松手滑进格子 |
| 藏起来 / 恢复 | 点操作条右边的 ✕ 隐藏;隐藏的块进底部「已隐藏的区块」托盘,点那个 chip 就恢复 |
| 退出 | 点底部工具条 **「完成编辑」** |
| 本页改坏了 | 工具条 **「重置本页」** = 本页回到默认 |

两条要记住的:

- **改动是即时保存的**,没有"保存"按钮;「完成编辑」只是退出编辑态(退出时会提示"布局已保存")。
- **撤销栈只在本次编辑态里有效** —— 退出再进来,历史就清空了(改动早就落盘了)。

## 二、手势速查表

| 手势 | 在哪用 | 说明 |
|---|---|---|
| 拖**手柄**换序 | stack 页(默认) | 块会**浮起来跟手**:要越过相邻块中点 **±6px** 才换位(滞回,手抖不会来回跳);其余块用 **170ms** 滑到新位置;松手后从手指位置 **170ms** 滑进自己的格子 |
| 拖**块** | grid 页 | 位移折成"格",整格移动,不会停在半格 |
| 拖**块** | canvas 页 | 自由拖动,按当前吸附档对齐 |
| 拖**缩放手柄** | grid 页 | 只有**右下三个**:右(e)、下(s)、右下(se) |
| 拖**缩放手柄** | canvas 页 | **八个方向**:四个角 + 四条边 |
| `Ctrl` 或 `Shift` + 点块 | grid / canvas | 多选:点一下选中,再点一下取消 |
| 在空白处按住拖 | grid / canvas | 拖出选框,框到谁选谁(**会先清掉原来的选择**) |
| 拖动中看辅助线 | grid / canvas | 与其它块的左/右/上/下/中线比对,**差 4px 以内**就磁性吸附并画线 |
| 拖动中靠近上下边缘 | stack / grid / canvas | 指针进到视口上下 **36px** 内就**自动滚动**(16ms 一帧,最多 18px/帧,越靠边越快),指针**停住也会继续滚**;落点/选框跟着内容一起走 |
| `Esc` | 编辑态 | 正在框选 → 只取消框选;否则退出编辑态 |
| `Delete` / `Backspace` | grid / canvas | 只删**自建块 / 插件块**;内置块会提示「内置区块不能移除」 |
| 方向键 | grid / canvas | 微调:grid 走"格",canvas 走"吸附格";按住 `Shift` = 10px 档 |
| `Ctrl+Z` / `Ctrl+Y`(或 `Ctrl+Shift+Z`) | 编辑态 | 撤销 / 重做 |
| `Ctrl+C` / `Ctrl+V` | 编辑态 | 复制选中的块(没选中就复制整页),粘贴到本页末尾;按 id 去重,所以同页重复粘贴不会造出重复块 |

三个容易踩的点:

- **多选和框选只在 grid / canvas 页有效**。stack 页没有自由坐标,只能拖手柄换序。
- **缩放手柄只在画布模式出现**;stack 页看到的手柄是"换序手柄",不是缩放。
- 工具条的「吸附」按钮管的是 canvas 栅格吸附档,循环切换 `0 → 4 → 8 → 16 → 24`,**默认 8px**(和上面的 4px 辅助线不是一回事)。

## 三、「分栏怎么拖」

| 问题 | 答案 |
|---|---|
| 分隔条长什么样 | 两栏之间那条**可命中的细线**(平时透明,鼠标悬上去才显出来),宽度就是原来那点留白 |
| 怎么拖 | 按住直接拖,松手就按新比例排;比例只认 15%~85% |
| 怎么复位 | **双击分隔条**;或 设置 → 布局 →「分栏比例」→ 那一处点「恢复默认」;底部「全部复位」一次清光 |
| 为什么有的页没有 | 因为那一处本来就不是左右两栏(见下表) |

**注意这条事实:界面上共 13 处分栏,其中只有 6 处是左右两栏、能拖**(所以你在别的页面找不到分隔条,是正常的,不是你点错了):

| 能拖的 6 处 | 拖的是哪一栏 | 现状 |
|---|---|---|
| 实例库 | 文件夹栏 | 星号比例 1/3(左卡 300~380) |
| 设置 | 左侧导航 | 168px |
| 版本管理 | 左侧版本列 | 272px |
| AI | 历史栏 | 220px |
| 反馈 | 右侧卡片 | 360px |
| 账号 | 头像卡 | 240px |

另外 7 处**不是左右栏**,没有可拖的分隔条:

- 实例详情分段是**横向 rail**(模组 / 存档 / 资源包 / 光影 / 设置);
- 启动页是**限宽(680)+ 限高(页高 62%)**;
- 下载页那一处是**列表行内的列宽**(在列表控件内部,不是页面分栏);
- 插件页那处是**网格列数**;
- 设置页「反馈与关于」、安装页都是**纵向分行**(标题/内容/底栏这种);
- 下载页另外 6 段内嵌的 catalog 页是**单列**。

> 例外说明:实例详情「设置」段里内嵌的版本管理**也是两栏**,但内嵌态隐藏分隔条、不写比例 —— 所以那一处也拖不了。

## 四、常见问题(FAQ)

### 1. 怎么加自建区块?(按钮已启用 + 三条 JSON 路径)

**图形入口从 2026-11-19 的 L6 起已经可用**(那天的构建也替换掉了 v1.2.0 的 Windows 附件,见仓库根 `update.json` 的修订说明):设置 → 布局 →「自建区块」→「添加自建区块」展开内联管理面板,再点「新建自建区块」填 类型 / 标题 / 参数 即可;页面**编辑态**的工具条里也有「+ 自建区块」,直接把这个块加到本页。新建出来的块不会自动挂到任何页面,必须先加进页面才会显示。

下面三条 JSON 路径**仍然有效**,适合批量改、跨机分享或让 AI 代改:

| 路径 | 怎么做 |
|---|---|
| ① 布局 JSON 卡片手写 | 设置 → 布局 → 最底下「布局 JSON」→ 粘贴下面的例子 →「校验」→「应用」 |
| ② 导入别人含 `widgets` 的整机方案 | 设置 → 布局 →「布局方案」→「导入布局」→ 选文件 →「应用为当前布局」 |
| ③ 让 AI 改 | 对 AI 说"在启动页加一个便签区块",它用 `layout_apply(widgets=[...])` |

**能直接粘的最小例子**(在 launch 页加一个便签 + 一个时钟):

```json
{
  "kind": "tipcl-layout",
  "version": 2,
  "layout": {
    "widgets": [
      { "id": "w-note",  "type": "note",  "title": "便签", "settings": { "text": "别忘了收菜" } },
      { "id": "w-clock", "type": "clock", "title": "时钟", "settings": { "format": "HH:mm" } }
    ],
    "pages": {
      "launch": {
        "version": 2,
        "blocks": [
          { "id": "custom:w-note" },
          { "id": "custom:w-clock" }
        ]
      }
    }
  }
}
```

三条路都遵守同一个两步规则:**先在 `layout.widgets` 里定义块,再在 `layout.pages.<页面>.blocks` 里加一条 `{"id": "custom:<widgetId>"}`**。只定义不引用,页面上什么都看不到。上面例子里没写出来的内置块会按默认可见性补到列表**末尾**。

粘 JSON 前请注意(重要):

- 「应用」是**整份替换**。上面这份省略了别的页面 → 应用之后**别的页会回到默认排布**。想留底先点「新建布局方案」;想只改一处,就用卡片里的「刷新」按钮取回当前文档,在它上面加两段。
- **`web` / `button` 默认不渲染**:必须给 `"settings": { "enabled": true }` 才会显示内容(否则显示"已禁用的自建区块"占位)。`web` 只认 `https://` 地址,`http` / 本地文件 / 脚本地址一律拒绝。
- 可选类型:便签 `note`(`settings.text`)、快捷启动 `shortcut`(`settings.instance`,可选 `settings.version`)、时钟 `clock`(`settings.format`,默认 `HH:mm`)、分隔线 `divider`、时长概览 `playtime`(可选 `settings.instance`)。

### 2. 怎么把某页改成网格 / 画布布局?

目前**没有界面下拉框**,两条路:

- 布局 JSON 里给那一页加 `"mode": "grid"` 或 `"canvas"`。可选值只有 `stack`(默认)/ `grid` / `canvas`;`grid` 时 `"cols"` 只认 2 / 3 / 4 / 6 / 12(其它值会被吸附到最近的档)。
- 让 AI 改,例如:`layout_apply(page="launch", mode="grid", cols=6)`。

⚠️ **canvas 只适合高度固定的页**:canvas 的画布高直接取可用高(不够就用参考高 600px),每块的 y / 高都是**按画布高的比例**算的,和内容实际多高无关。长列表、会换行的卡片这类**高度不定**的页,用 canvas 会被拉满 / 压扁 —— 高度不定的页请用 `stack` 或 `grid`。
(未实测:真机上各页在 canvas 模式下的实际观感)

### 3. 窄窗和宽窗布局在哪设?

**不能手动设,也没有地方设** —— 是运行时按窗口宽度**自动切**的:内容区可用宽 **小于 760px** 时用 `variants.narrow` 那一份,否则用主 body;某页在 `variants.narrow` 里没有条目就沿用主 body。
(实现里注明:760 这个阈值在设计文档里没给具体数值,是**推断值**,而且要改它得改代码 —— 界面上没有入口。你能在布局 JSON 里安排的,是 `variants.narrow` 里放哪个页面的哪一份排布。)

### 4. 改坏了怎么办?

| 坏的范围 | 怎么做 |
|---|---|
| 只坏了一页 | 进编辑态 →「重置本页」(回到该页默认区块顺序与显隐) |
| 分栏比例乱了 | 设置 → 布局 →「分栏比例」→ 那一处的「恢复默认」;底部「全部复位」一键清掉所有存储比例 |
| 整份都乱了 | 删掉数据目录里的 `ui_layout_v2.json` |

⚠️ 只删 `ui_layout_v2.json` 会**回落**到 `ui_page_layouts.json` 那份 v1 投影 —— 每页的**区块顺序 / 显隐会照旧保留**,不会回到默认。要彻底回默认,得连 `ui_page_layouts.json` 一起删掉或改名。

### 5. AI 改完想撤回?

AI **每次应用前**会自动把"改之前"的布局存成一份方案,名字是 `AI 备份 <时间>`,例如 `AI 备份 2026-11-15 15:20:31`;**最多保留 5 份**,按名字倒序把旧的自动删掉。
撤回:设置 → 布局 →「布局方案」→ 找到那句 `AI 备份 ...` → 点「应用」。

### 6. 我的布局能分享给别人吗?

能,但**仓库没有内置分享通道**,靠导文件:设置 → 布局 →「布局方案」→「导出布局」→ 选 **「导出整机方案(v2)」** → 存成 json → 把文件发给对方;对方在同一个位置「导入布局」→ 选文件 → **「应用为当前布局」**(也可以选「存为方案」先留着不生效)。
那份整机方案包含:页签与标题栏、各页区块顺序与显隐、页面模式与列数、分栏比例、自建区块。另一个选项「导出兼容 v1 的页面布局」只含每页的顺序与显隐。

### 7. 旧版本会不会读不了新布局?

不会。布局 v2 的真源是 `ui_layout_v2.json`,**新字段全部写在这个文件里**;旧版本根本不认识这个文件名,它读的是由新版本**单向写通**的 `ui_page_layouts.json`(只有 version / kind / 每页 `{id, hidden}` 这么点字段)。
所以旧版本照旧读得懂顺序与显隐,读**不到**的是网格 / 画布 / 分栏比例 / 自建区块这些新东西 —— 那些地方会退回默认排布,不会报错。

### 8. 改布局会不会影响游戏或实例数据?

不会。布局只写数据目录里的两个文件:`ui_layout_v2.json`(真源)和 `ui_page_layouts.json`(v1 投影)。实例、存档、模组、账号全都不在这条链路上。

### 9. 为什么有些页面右键没有「自定义布局...」?

右键菜单只在**页面有 2 个以上区块**时才出现(单块页连"顺序"都没得排,所以不给这项)。单块页(下载与网络 / 反馈与关于)请走 **设置 → 布局 →「页面区块」**里的入口 —— 那里按"≥1 个块"判定,单块页也能进去调外观 / 标题 / 先隐藏。
另外,页面内容自己带右键菜单时,**页面自己的菜单优先**,这时也请改走设置页入口。

### 10. 拖到页面底部拖不动 / 块在手指边上抖,是 bug 吗?

都不是,是 2026-11-20 这版**故意**做成这样的手感(Windows 桌面版):

| 现象 | 实际行为 | 出处 |
|---|---|---|
| 拖到页面底部/顶部就停住 | 指针进到视口上下 **36px** 内会**自动滚动**(16ms 一帧,最多 18px/帧,越靠边越快),指针停住也继续滚 | `LayoutEditor.cs:1858-1888`、`StackDragPlan.cs:73-99` |
| 块跟着鼠标走但"推过去不换位" | 这是**滞回**:必须越过相邻块中点 **±6px** 才换,避免手指在中点附近 1~2px 抖动时两块来回跳 | `StackDragPlan.cs:21`(`Hysteresis = 6.0`) |
| 松手时块"自己滑回去" | 这是**落位动画**(170ms,从手指位置滑进格子);`Motion.Enabled = false` 时没有动画、瞬间落位 | `LayoutMotion.cs:19`、`LayoutEditor.cs:1831` |
| 旁边那块"跳过去" | 是 FLIP 让位(170ms 从旧位置滑到新位置),不是瞬移 | `LayoutMotion.cs:16,78-81`、`LayoutEditor.cs:1753` |

> Linux 版**不是**这套手感:它进编辑态会把 stack 页临时折成 12 列网格,拖拽是"像素跟手 + 到格就换",边缘滚动是 30ms / 48px / 每帧最多 28px。详见 [docs/README.md](README.md)「Linux 编辑态与 Windows 的四处差异」。
