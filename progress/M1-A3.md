# M1-A3 · 窗口外壳与导航框架

## 做了什么
按 GOAL §5-M1-A3 完成 Avalonia 主窗口外壳与导航框架（参照 Windows 版 `MainWindow.xaml(.cs)` 与 v2 设计图 `docs/mockups-hark/v2/`）：

- **主窗口** `Shell/MainWindow.axaml(.cs)`：1180×740（Min 720×480），`ExtendClientAreaToDecorationsHint` 自绘标题栏（Linux 下保留系统缩放边框，GOAL 允许）。内置导航状态机 `Navigate(id)`（页缓存 + 同步侧栏/页签高亮）与明暗主题切换 `SetDark/ToggleTheme`（交换合并资源字典）。
- **标题栏** `Shell/TitleBar.axaml(.cs)`：40px；Logo（22×22 圆角 "T" 主色块）+ 顶部 5 页签占位（启动/实例库/下载/插件/设置，选中底部 2.5px 主色条加粗）+ 明暗主题切换钮（月/日矢量）+ 最小化/最大化/关闭。窗口按钮 46×40 满高，矢量线宽 1.1 圆头，关闭悬停 `#C42B1C` 满高白字。整条标题栏可拖动窗口、双击切换最大化（按在按钮上不抢）。
- **侧边导航** `Shell/SideNav.axaml(.cs)`：196px 分组导航——通用（仪表盘/账号/Java）、游戏（实例库/下载/任务）、系统（插件/设置/关于）；选中态白底胶囊（CornerRadius 8）粗体 + 细描边。
- **导航注册** `Shell/NavRegistry.cs`：侧栏分组与顶部页签的静态注册表，M2 换真实页面只改 MainWindow 的页工厂。
- **占位页** `Pages/PlaceholderPage.cs`（基类：卡片 + 页标题 21 bold + "该页面将在 M2 移植实现。"）+ 10 个 `Placeholder*.cs`（Launch/Dashboard/Account/Java/Library/Download/Tasks/Plugins/Settings/About）。

## 主题键（已对齐 A2）
A2 的 `Themes/Palette.Light|Dark.axaml`（`B.*` 键）落地后，外壳令牌已收敛为对 A2 键的**转发别名**：`ShellTokens.Light|Dark.axaml` 内每个 `Shell.*` 键通过 `<StaticResource ResourceKey="B.*"/>` 指向 A2 同义键（PageBg→B.Canvas、TitleBarBg→B.Chrome、CardBg→B.Card、Accent→B.Accent、CaptionCloseHoverBg→B.CaptionHot(#C42B1C) 等）。MainWindow 合并字典时 Palette 与 ShellTokens **成对合并**（浅色两张 / 深色两张）。外壳后续调色只需动 A2 的 Palette，Shell.* 别名是稳定引用点。

## 自证编译
- 因同工程 A2 的 `Ui/` 文件在收尾时仍有其自身缺 using 的错误（非 A3 文件，A2 修复中），A3 采用**隔离编译自证**：把 `Shell/` + `Pages/` + A2 的 `Themes/Palette.*.axaml` 复制到临时目录，用等价 csproj（Avalonia 11.3.2，AssemblyName=TipCL.App 以便 avares URI 解析）独立 build——**0 错误 0 警告**。隔离构建还揪出并修复了两处真实缺陷：SideNav 缺 `using Avalonia.Controls.Shapes`（`Path`），以及 Avalonia 11.3 中 `ResourceInclude` 无无参构造 / `ResourceDictionary` 无 `Source` 属性（XAML 与 C# 均改用 `ResourceInclude`）。
- 整工程 `dotnet build src/TipCL.App -c Release` 绿灯以 A2 修复 `Ui/UiHelpers.cs`（PasswordBox using）后为准。

## 遗留 / 风险
- 主题切换用「清空并重挂 MergedDictionaries（Palette + ShellTokens 成对）」实现，Avalonia DynamicResource 会随动；若 A2 全面转向 ThemeVariant 方案需重接（改动集中在 MainWindow.SetDark 一处）。
- 最大化/还原图标随 `Window.WindowStateProperty` 切换；Win11 系统圆角/贴边等 Windows 专属特性未做（M3 在 Linux 真机处理）。
- 未加窗口拖拽缩放的 GrabArea（NoChrome + Full SystemDecorations 由系统边框承担）；若 Linux 真机边框不可缩放，M3 再补 `ExtendClientAreaChromeHints.SystemChrome` 方案。
- 仓库根下的 `.probe_tmp*` 临时隔离构建目录如未删净可安全手动删除（纯构建产物）。
