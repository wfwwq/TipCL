### 3. LaunchCore 门面（src/TipCL.App/Common/Launch/LaunchCore.cs，新建）

Windows 版 BackendApi._launch_game_impl（约 230 行）的 Avalonia 进程内移植：

- **流程**：版本校验 → 多开检查（allow_multi_instance）→ Preflight.CheckLaunch（error 级不通过抛 LaunchError，force 可跳过并记日志）→ 设默认实例 → 版本绑定账号优先 → RequireLaunchAccount（离线/皮肤站/统一通行证）→ LaunchFlow.Prepare（内存/分辨率/隔离/game_dir/钩子命令）→ pre_launch 钩子 → Java 解析链（参数 → 版本设置 → 实例 JavaPref → 全局 default_java → ResolveLaunchJava，不够格自动下载）→ Authlib 注入器/Nide8 jar 自动补 → McLauncher.BuildLaunchCommand → GameProcess 拉起 → post_launch 钩子 → Crash.AnalyzeLaunch，崩溃抛 GameCrashError（Report 字典随任务失败信息回传）。
- **日志桥**：stdout/stderr 逐行 → TaskProgress.Log（任务卡）+ IApi log 事件；下载进度 → progress 事件（对齐 Windows 版 _dm 的 `  |  ` 拆分去重）。
- **事件**：game_started / game_exited（instance/version/pid/exit code）。
- **进程跟踪**：静态 Current Process + 锁，`IsRunning`（is_game_running）/`Stop()`（stop_game，整棵进程树 Kill）。
- **辅助**：MakeDownloader（带进度/取消的 DownloadManager）、RequireLaunchAccount、IsOfflineAccount、NormalizeJavaPref。
- **未接入**：插件 launch.before/after、PluginManager.GameLog 钩子（Core/Plugins 宿主运行时未搬，M3-C1 地盘；其它路径不影响启动）。
- `InstancesApi.EnsureInstance`（对齐 BackendApi._instance：不存在则建）。
