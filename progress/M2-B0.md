## 依赖申请（需外壳/页面包配合）

1. **外壳（A3/MainWindow）**：页面接线用 PageBase 生命周期——`ShellAttach(parameter)`（首次触发 OnCreate，再 OnNavigate+OnActivate）、切走时 `ShellDetach()`、事件流转发 `ShellEvent(ApiEvent)`；占位页替换 NavRegistry 工厂行即可（M2-B0 不改 Shell/）。明暗切换后请调 `ThemeService.Replay()` 重放主题色覆盖（MainWindow.SetDark 清了 merged dictionaries，但 B.* 覆盖键写在其上不受影响；Replay 保证派生键随明暗重算）。
2. **B4（布局自定义）**：钩子位是 `PageBase.LayoutWrapper` 静态委托 `(pageId, inner) => Control`，BlockHost 初始化时设置即可，无需改 PageBase。
3. **页面包（B1–B5）**：API 调用一律走 `PageBase.Api`（InProcessApi.Instance）；本地任务入队走 `TaskStore.Add/Handle`，任务角标订阅 `TaskStore.Changed`。
4. **页面包注意 `Ui` 名字冲突**：`TipCL.App.Ui` 既是命名空间又是 A2 的门面类名，页面文件直接写 `Ui.H(...)` 会被解析成命名空间成员而报 CS0234。页面文件请加别名 `using Ui = TipCL.App.Ui.Ui;`（Common/ 内部均按此写法）。
5. **B5 SettingsPage** 在外部调用 `child.OnActivate()/OnDeactivate()`——生命周期钩子是 protected，外部请改走 `ShellAttach(parameter)` / `ShellDetach()` / `ShellEvent(ev)`（internal，同程序集可调）。

4. IconLib 为同语义重绘而非字形逐点转刻（无字体矢量源可提取）；如需与 Windows 版逐像素一致，需从 TipCLIcons.ttf 用字体工具导出字形轮廓（M3 可选）。
