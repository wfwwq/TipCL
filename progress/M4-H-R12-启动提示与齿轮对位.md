# M4-H R12:启动提示时序 + 版本行齿轮对位

状态:完成(子代理执行;主 agent 复核 + 真机验收)

## 背景:真机验收时新发现的两个缺陷

R11 的真机差分验收(2026-11-13 01:4x–02:3x,box `main`)顺带暴露两处遗留问题。

### 缺陷 1:每次启动都 WARN,真实首启时首启向导与同意门双双静默失效

真机(avalonia GUI)日志,**每一次**启动都出现:

```
17:53:33.135 [INFO] === TipCL 0.1.0-m3 启动 pid=84818 os=Unix 6.8.0.142 ===
17:53:34.125 [WARN] 启动提示失败: Cannot show window with non-visible owner.
```

成因链(经真机差分确认到「哪一步抛」):

- `src/TipCL.App/App.axaml.cs:22-26`:`desktop.MainWindow = win;` 之后**立刻** `_ = win.RunStartupPromptsAsync();`,此时主窗口尚未 `Show()`;
- `src/TipCL.App/Shell/MainWindow.axaml.cs`:`RunStartupPromptsAsync` 先跑 `FirstRunWizard.MaybeShowAsync()`,它**没有延迟**,当场弹面板 → `Dlg` 内部 `ShowDialog(owner)`,而 owner(主窗口)还不可见 → Avalonia 抛
  `InvalidOperationException: Cannot show window with non-visible owner.`;
- 异常被 `catch` 吞成 WARN,并**中断整个 `RunStartupPromptsAsync`** → 排在后面的 `FeedbackConsent.MaybeAskAsync`(自带 400ms 延迟,单独跑其实弹得出来)一次都轮不到;
- ⇒ **真实首启时用户既看不到首启向导、也看不到同意门**,`first_run` 永远停在 `true`,每次启动重复这条 WARN。

> 纠正一处早期判断:说「同意门因为 owner 不可见而弹不出来」只对 `first_run=true` 成立。实测 `first_run=false` 的 fixture(向导不跑)时,修复前的产物也**能**弹出同意门 —— 真正把整串提示打断的是向导那一步。

Windows 参考时序(`windos/.../MainWindow.xaml.cs:362-369`):首启向导与同意门都是在窗口加载 **且** bridge 连接完成之后才 await 的。

### 缺陷 2:实例库版本行齿轮「挂羊头卖狗肉」

| 位置 | tooltip | 实际动作 |
| --- | --- | --- |
| Windows `Pages/LibraryPage.cs:713-720` | 版本设置 | `VersionSetupDialog.ShowAsync(inst, id)` + `LoadAsync()` |
| Linux `LibraryPage.cs:539-540`(修复前) | 版本设置 | `OpenDetailAsync(id)`(打开实例详情页) |

后果不只是文案不符:真机上正是这个入口把用户送到 `InstanceDetailPage`,撞上 R9 的崩溃,并且在排查初期把崩溃错误归因到「版本设置」对话框(R8 归因错误)。

## 修法

1. `MainWindow.RunStartupPromptsAsync` 先等主窗口**真正可见**再跑两个提示:新增 `RunWhenVisibleAsync` / `WaitUntilVisibleAsync`(判定用窗口状态:`Opened` 事件或 `Visual.IsVisible` 变真,任一成立即可,上限 15s;续接用 `TaskCompletionSource(RunContinuationsAsynchronously)` 投回 Dispatcher,不在 `Show()` 的调用栈里跑提示);窗口一直不可见时记一条**文案不同**的 WARN(「主窗口 15000ms 内没有可见,启动提示已跳过」),以便与「弹窗仍然抛异常」区分。`--smoke` 语义不变。
2. `LibraryPage` 版本行齿轮改为 `VersionSetupDialog.ShowAsync(inst, id)` + `LoadAsync()`(与 Windows 对位),tooltip 保持「版本设置」;「实例详情」chip(`:130`)与实例卡片右键菜单两个正当入口未动。
