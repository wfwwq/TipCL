## 做了什么

### 1. 布局框架模型层（Core/Layout，零 UI 依赖）

| 文件 | 说明 |
|---|---|
| `src/TipCL.Core/Layout/PageBlock.cs` | BlockState / PageLayoutDoc（Default / Normalize / FromJson / ToDict / ToJson），逐行搬 Windows 版 `Pages/PageBlock.cs`，仅改命名空间 |
| `src/TipCL.Core/Layout/PageLayoutStore.cs` | `ui_page_layouts.json` 持久化（原子落盘、吞异常、DirOverride、缓存跟目录走）。Windows 的 `BridgeHost.FindRoot()` 换成 `RootProvider` 委托（App 侧接 `Core.Utils.ROOT`，异常回退语义保留） |
| `src/TipCL.Core/Layout/PageLayoutIO.cs` | 导出/导入的模型部分（ExportToFileDialog / ImportFromFileDialog / ParseImport 中文异常）。文件对话框与 Toast 抽成静态委托（SaveFileDialog / PickFileDialog / Toast），保持 Core 零 UI；另有 `LayoutText.L`（I18n 键即中文文案的透传等价）与 `ToastKind` 枚举 |

### 2. 契约测试

`tests/TipCL.Tests/Layout/PageLayoutTests.cs`：Windows 版 15 个 [Fact] 逐条搬入（Default 保序标隐、Normalize 剔未知/补尾/保已有/空 id、FromJson 布尔语义/坏版本/去重/缺 blocks、ToJson 往返、Save→Load 临时目录往返、坏文件、ExportImport 往返、ParseImport 跳坏页、错 kind/version 抛异常、空 pageId）。**15/15 全绿**。

### 3. BlockHost（Avalonia 重写，App/Pages/Layout/）

- `BlockHost.cs`：BlockSpec（Content 为 Avalonia Control）+ 区块卡 + 编辑模式（托盘/工具条/重置/导出/导入）+ 持久化，结构树对齐 Windows 版。拖拽 = 缓存各可视块 `Bounds.Height` + 逐格与相邻块中点（高度+Gap=10 累加）循环交换，不做动画插值；指针捕获走 Avalonia Pointer API（PointerPressed 时 `e.Pointer.Capture`，PointerMoved/Released/CaptureLost 收尾），按 R3 §6 逐条落实。编辑态 1.4px B.Accent 描边 + 10 透明度蒙版。右键「自定义布局…」挂在 BlockHost 根（specs.Count>=2），文档化冲突规则：**挂 BlockHost 的页面不得再在根上挂自己的 ContextMenu**（Avalonia 无属性继承链合并）。
- `PageBase.LayoutWrapper` 钩子（B0 预留）保持未设（null = 原样返回）；需要布局自定义的页面直接 `new BlockHost(pageId, specs)` 包内容。pageId 约定 `<pageKey>` / `<pageKey>:<viewKey>`。
- `PageLayoutIO` 的对话框/Toast 委托由 `LayoutFx.Wire()`（App 启动时调用，已接在 App.axaml.cs）转发到 B0 的 `Dlg.SaveFile/PickFile` 与 `ToastHost.Show`（含 Core.Layout.ToastKind → Common.ToastKind 映射）。

- 市场卡片：48×48 图标框、标题行（vTag/已审核/未审核/.NET）、meta 行、描述截断、标签前 6、详情按钮、安装/更新/已安装按钮；排序（可更新>已审核>下载量>名称）、标签 Chip 单选 Top24、搜索四字段、详情弹窗（头部/简介/权限列表/更新日志，操作按钮钉底）。

### 5. 数据面决定（R3 §7 降级口径）

- 列表/启停/卸载/本地安装/开发链接走 **Core 的 PluginStateStore + PluginDirs + PluginManifest**（B0 已搬）；市场索引经 **Core.PluginMarket** 直连（镜像/索引地址读同一份 config.json，与 Core 语义闭环），`InstalledVersionOf` 注入 state store。
