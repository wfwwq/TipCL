自定义布局 v3：编辑态和「设置 → 布局」两张效果图

两张都能直接操作。每张右上角在「新版 / 现状」之间切换，用来对照现在的截图。两张是联动的：在「设置 → 布局」里改间距、改页签，或者点「下载」卡片上的「编辑」，第一张会跟着变。

主题色

编辑态：内容是主角，编辑控件只在需要时出现「下载」页。拖动块调整顺序；网格模式下拖块的右边缘改宽度；悬停能看到块名和隐藏 / 删除按钮。

组件
网页、按钮组件默认关闭，可在 设置 → 布局 → 高级 里开启。
  • 边框：红色实线改成灰色虚线，只有选中的块用主题色。
  • 块名：悬停才出现；自建组件显示自己的标题，不再显示 w_note1。
  • 工具条：7 个文字按钮改成顶部一条：列表/网格、撤销重做图标、添加、重置本页、完成。
  • 吸附：去掉「吸附 N」；网格按列对齐，宽度只能是整数列。
  • 隐藏托盘：并进「添加」抽屉，按钮上的数字表示隐藏了几项。
  • 隐藏和删除分开：内置内容用眼睛图标隐藏，自建组件用垃圾桶删除。
  • 模式：从 JSON 搬到界面，只留列表 / 网格两种，不再提供自由画布。
  • 单块页面：（如「下载与网络」）不提供编辑入口。

设置 → 布局：从配置清单改成按要做的事分组拖动页签排序、点眼睛隐藏，标题栏会马上变；改间距会同时反映到缩略图和上面那张编辑态。
