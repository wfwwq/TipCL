# 界面截图存档(docs/ui-audit)

本目录是界面审计与交付验收时的整窗截图。**写文档 / 发版说明要引用界面图时,只取 `hero/` 那一组。**

| 目录 | 内容 | 状态 |
|---|---|---|
| `hero/` | 交付用的整窗截图:启动页(浅色 / 深色)、实例库、下载、设置、插件、实例切换浮层 | **当前界面**,可直接引用 |
| `launch/` | v1.0 界面的启动页审计截图(左侧栏那一版) | 历史存档,**不代表当前界面**,别拿去做文档 |
| `sheet/` | v1.0 设计规范样张页(明 / 暗各一张) | 历史存档,**不代表当前界面** |

截图怎么来的:用 [`tools/shot-window.ps1`](../../tools/shot-window.ps1)(启动 exe → 等窗口出现 → 截窗口矩形)。
界面改动后请重拍 `hero/`,并保持文件名不变 —— README 与发版说明都按这些文件名引用。

## `hero/` 的 7 张固定文件名

README 与发版说明都按下面的文件名引用,重拍时**不要改名**:

| 文件 | 页面 |
|---|---|
| `launch-light.png` | 启动页,浅色主题(README 首图,按 640 宽显示,原图 1280×782) |
| `launch-dark.png` | 启动页,深色主题 |
| `pop-dark.png` | 启动页,深色主题 + 实例切换浮层 |
| `library-light.png` | 实例库(左侧文件夹列表 + 右侧版本选择) |
| `download-light.png` | 下载(原版 / Mod / 整合包 / 数据包 …) |
| `plugins-light.png` | 插件(已安装 / 市场) |
| `settings-light.png` | 设置 · 通用 |

除 `launch-light.png` 是 1280×782 外,其余都是 900×550;文件名里的 `light` / `dark` 是主题。
拍摄时窗口里只留启动器本体(含自绘标题栏的 5 个页签:启动 / 实例库 / 下载 / 插件 / 设置),不要桌面和任务栏。
