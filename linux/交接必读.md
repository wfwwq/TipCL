# 交接必读

> 新接手的 agent 从这里开始。读完本文件 + `GOAL.md`（全文）+ `PROGRESS.md` 后再动手。

## 口令

**TipCL Linux 版立项，按 GOAL.md 继续。**

## 项目一句话

把 Windows 版 TipCL（WPF / .NET Framework 4.8 的 AI 原生 Minecraft 启动器，参考仓库 `D:\项目\tipcl\windos\tipcl\`，**只读**）立一个 Linux 版：Avalonia 11 / net8.0，M1 只做工程骨架（可编译空壳 + Core 复用层 + 测试/构建基建）。

## 工作规则（参照 Windows 版协作方式）

1. **主 agent 监工，子代理干活**：子代理只负责自己被分派的工作包，做完自证、写报告、commit，然后交回主 agent 验收。
2. **文件独占**：只写自己工作包独占地盘内的文件（GOAL §5 有分配表）；共享文件（sln、GOAL/PROGRESS/DECISIONS）编辑权归属见 GOAL §6——PROGRESS/DECISIONS 只能**追加**自己的小节，禁止重写他人内容。
3. **收尾三件套**：a) 自证 `dotnet build`（自己范围）0 错误；b) 写 `progress/M1-<包>.md`（做了什么、文件清单、遗留、风险）；c) git commit，信息前缀工作包编号（如 `M1-A2 xxx`）。
4. **构建防锁**：build 前 `dotnet build-server shutdown`；遇 CS 文件锁报错先 shutdown 再重试。
5. **红线**（GOAL §3 全文有效）：不碰 Windows 参考仓库；M1 依赖白名单只有 Avalonia 11.x 全家桶 / Avalonia.Themes.Fluent / xunit / Microsoft.NET.Test.Sdk，其它包需在 DECISIONS.md 报备；不碰版本号、不 push、不发 release；界面文案中文。
