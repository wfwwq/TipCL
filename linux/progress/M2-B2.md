## 依赖申请（写给他包/主 agent）

1. **`Ui` 命名空间遮蔽（重要，全局横切）**：在 `namespace TipCL.App.Pages.*` 内写 `Ui.Xxx`，`Ui` 会被解析成命名空间 `TipCL.App.Ui` 而不是类（CS0234）。解法：文件头加 `using UiClass = TipCL.App.Ui.Ui;`（B0 在 PageBase 用了同款 `UiFacade` 别名）。本包两个页面文件均用 `UiClass.`。
2. **MainWindow.axaml.cs 属共享文件**：本包只改了 `library` 一行（完全限定写法）。文件当前工作区状态还带着 B1/B3/B4/B5 未提交的注册行，提交时一并入库属正常合并点，注册冲突由主 agent 裁决。
3. **页内跳转接线**：`LibraryPage.NavRequested`（public static Action<string>，事件语义但需外部 Invoke 故用字段）已由 MainWindow 构造函数一行接线（`NavRequested += id => Navigate(id)`），双击版本/详情页「启动」→ 设默认实例后跳启动页。
4. **B0 依赖**：PageBase/IApi(InProcessApi)/Dlg/Toast/Motion/IconLib 已就位并使用。**缺口**：IApi 未实现 `get_version_rows / list_saves / open_instance_folder / uninstall_version / import_existing_folder / get_installed_resourcepacks / get_installed_shaders / delete_resourcepack / delete_shader`，页面先走 IApi snake_case 调用、NotImplementedException 时回落 Core 直调（Instances/VersionSettings/Saves/Mods），M3 补 IApi 方法表后自动切换。收藏/折叠态暂为进程内静态字典（B0 UiPrefs 缺口 B，落地后替换）。
