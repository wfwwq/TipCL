# M1-A2 · 设计令牌与主题库

## 做了什么
- 移植 Windows 版 v2 设计令牌到 Avalonia：`Themes/Palette.Light.axaml`、`Themes/Palette.Dark.axaml`（明暗成对，色值/键名照抄 Windows 版 `src/TipCL/Themes/Palette.*.xaml`，键集 diff 已验证 100% 一致）。
- `Themes/Controls.axaml`：Avalonia 11 ControlTheme 版控件样式（按钮 7 档 / 输入框 / 下拉 / 复选 / 开关 / 卡片 / 标签 / 徽章 / 分段控件 / 顶部页签 / 进度条 / 工具提示 / 文本阶梯）。
- `Ui/UiHelpers.cs`：移植 Windows 版 `Services/Ui.cs` 门面 API 到 Avalonia（code-behind 风格，DynamicResource 观察绑定，明暗切换即时生效）。
- `Ui/ThemeGalleryPage.cs`：样张页，展示全部令牌色板 + 控件的明暗两态（顶部有"切换明暗主题"按钮）。A5 冒烟可直接把它设为窗口内容截图。

## 挂载方式与依赖申请（重要，给 A1/A3/A5）
- **依赖申请（App.axaml 归 A1）**：建议在 `App.axaml` 的 `<Application.Resources>` 增加合并字典：
  ```xml
  <ResourceDictionary Source="avares://TipCL.App/Themes/Palette.Light.axaml" />
  <ResourceDictionary Source="avares://TipCL.App/Themes/Controls.axaml" />
  ```
  不加也能跑：`Ui.ApplyTheme(bool)` 首次调用时会经 `Ui.EnsureMounted()` 把 Controls.axaml 代码挂载进 Application.Resources 并按参数挂对应 Palette（这就是 ThemeGalleryPage 上的切换按钮的工作方式）。
- **给 A3**：外壳可用键名即上表；`Ui.ApplyTheme(dark)` / `Ui.ThemeChanged` 事件可做标题栏主题切换钮。A3 当前自建的 `Shell.*` 令牌（红 accent #C9403F）与 A2 令牌（绿 accent #2E9B6B，Windows 版同款）不一致，属临时实现，按 GOAL §5-M1-A3 收尾时请对齐到本表键名。
- **给 A5**：冒烟截图可 `new Window { Content = new TipCL.App.Ui.ThemeGalleryPage() }`，或先 `Ui.ApplyTheme(true/false)` 再截图，验证明暗两态。

## 平台差异 / 偏离说明
1. **PasswordBox**：Avalonia 11.3.2 无 `PasswordBox` 控件（已用反射核实核心包无此类型）。`Ui.Pw()` 用 `TextBox.PasswordChar='●'` 等价实现；Controls.axaml 不含 PasswordBox 主题（复用 TextBox 隐式主题）。Windows 版对应 Ui.cs 的 Pw 密码框。
2. **XAML 语法差异**：WPF 的 `StrokeStartLineCap/StrokeEndLineCap`（Avalonia Path 无此属性，已去掉 caps）；`ProgressBar.IndicatorWidth` 不存在，Avalonia 由控件代码自动设置 `PART_Indicator` 宽度；TextBox 模板必须含 `PART_TextPresenter`（占位符改用该 presenter 的 Text 绑定控制可见性）。
3. **图标字体**：Linux 无内置 Segoe Fluent Icons，`Ui.Glyph` 在缺字体时回退普通文本显示（M2 若需矢量图标再议）。
